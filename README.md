# BitField

![badge](https://gist.githubusercontent.com/Bagolly/d84251f0d4ab9946ba92c6f1ae25ef79/raw/4f2b9206b4ba17e32c6d5723d26518f9c7771f80/bitfield-code-coverage.json)

Contains a generic bitfield type. Currently, the following types are tested
 - `byte`
 - `char`
 - `ushort`
 - `uint`
 - `ulong`
 - `nuint`
 - `UInt128`

but technically any type implementing the required interfaces can be used.
