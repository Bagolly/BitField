# BitField

![badge](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/Bagolly/d84251f0d4ab9946ba92c6f1ae25ef79/raw/bitfield-code-coverage.json)

Contains a generic bitfield type that can operate over finite unsigned binary integers. Currently, the following types are tested
 - `byte`
 - `char`
 - `ushort`
 - `uint`
 - `ulong`
 - `nuint`
 - `UInt128`
